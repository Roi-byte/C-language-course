C-language-course:

Coded by Roi-byte, this repository contains all my projects and exercises from my C programming course — each earning a perfect score (100).
The collection demonstrates a strong understanding of ANSI C (C90), built and tested entirely in a Linux (Ubuntu) environment.

Features:

Comprehensive coverage of C programming fundamentals:

Pointers, arrays, and strings

Dynamic memory management (malloc, calloc, free)

Structs and modular design using .h and .c files

File I/O and command-line argument handling

Algorithmic exercises (sorting, searching, recursion)

Basic data structures (linked lists, stacks, queues)

Strictly follows the C90 standard

Each project is well-commented, readable, and self-contained

Designed for execution in a Ubuntu/Linux environment
